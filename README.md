# EB Doc - Skin Assessment Application 🌸

تطبيق **EB Doc** هو تطبيق مخصص لتقييم وصحة البشرة، يهدف إلى مساعدة المستخدمين على تقييم حالة بشرتهم بسهولة وبخطوات سلسة.

---

### 🎨 الهوية والتصميم (Design & Theme)
- **الألوان الأساسية (Color Palette):** الوردي والأبيض (Pink & White)
- **نمط الواجهات (UI Style):** تصميم بسيط وعصري بإطارات مستطيلة ذات حواف حادة وأنيقة.

---

### ✨ مميزات التطبيق (Key Features)
- **تقييم البشرة (Skin Assessment):** سير عمل سلس وواضح لتقييم حالة البشرة وتقديم إرشادات مناسبة.
- **واجهة مستخدم بسيطة (User-Friendly Interface):** سهولة التنقل بين شاشات التطبيق والخطوات.

---

### 📋 مخطط التدفق (Flowchart Workflow)
يقوم التطبيق على مخطط تدفق متكامل لتقييم البشرة يشمل:
1. البداية وتحديد نوع المشكلة / التقييم المطلوبة.
2. الإجابة على الأسئلة التقييمية الخاصة بالبشرة.
3. عرض نتائج التقييم والتوصيات المناسبة.
